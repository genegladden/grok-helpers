Add the 2 GitHub secrets

For the to-grok issue handler. About 2 minutes. Follow the steps in order.

🔒 This page never sends, saves or shares anything. It has no internet code at all. You do the pasting yourself.

1Copy the Webhook URL

Open the Grok Bot app → Routines tab → to-grok issue handler. Copy the Webhook URL.

2Add the URL secret

Open GitHub new secret page
  1. Paste the name in the Name box.
  2. Paste the Webhook URL in the Secret box. (Go back to the Grok Bot app to copy it again if needed.)
  3. Tap Add secret.

3Add the Authorization secret

In the Grok Bot app (same routine), copy the Authorization header. Copy the whole value exactly as shown.

Open GitHub new secret page
  1. Paste the name in the Name box.
  2. Paste the whole Authorization header in the Secret box.
  3. Tap Add secret.

4Optional: check the URL

Paste the Webhook URL here to see if it looks right. The check happens only on this page. Nothing is sent or saved, and the box clears when you tap a button.

5Check it worked

Check: open the secrets list

Under Repository secrets you should see both names:

🔒 TO_GROK_WEBHOOK_AUTH
🔒 TO_GROK_WEBHOOK_URL

GitHub never shows the values again. That's normal. If a name is missing or misspelled, add it again.

6Then tell Grok Bot: done
